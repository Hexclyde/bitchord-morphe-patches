# Soulseek on BitChord 1.9

Select **Unofficial Soulseek audio** in Morphe for an original BitChord 1.9 APK. Supported architectures are arm64-v8a, armeabi-v7a and x86_64 on Android 8 or newer; 32-bit x86 is unsupported.

The Soulseek patch works independently when **Phone** is the destination. **Telegram main channel** or **Both** also requires **Unofficial Telegram music**, a connected account and an owned private main channel. Configure destinations, formats and credentials under **Settings → Patches & tweaks**. See [Soulseek setup and downloads](SOULSEEK.md).

A patched APK needs the same package name and signing key to update an existing installation. **Install as Bitchord+** provides a separate installation when selected. Soulseek files download completely before saving; [Streamseek previews](STREAMSEEK-PREVIEW.md) supplies optional explicit previews.
