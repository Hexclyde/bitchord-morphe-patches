# 1.1.0-beta.18

I retain the complete beta.17 feature set and add native local playlist generation, Storage Sense cache review, expanded Sing separation, Play alongside other apps, Steady playback and source-independent Smart downloads. I refine peer downloads, preserve native download settings, and restrict FLAC Downloader to downloads.

I install the supplied MPP as a local source in Morphe, select the original BitChord 1.9 APK for my device architecture, and retain the signing key used for my installed app. I leave new playback features off until I explicitly enable them.

I provide the [feature guide](BETA18-FEATURES.md) and [verification report](VERIFICATION-1.1.0-beta.18.md) with the supported behavior and test limits. I keep Windows publishing helpers in the ZIP only; I publish no release from this working session.
