# Transition editor

Select **Source-independent AutoMix**, enable Automix in BitChord's Playback settings and add two tracks with known durations to the queue. Open **Transition editor** in Patches & tweaks.

The timeline shows the outgoing and incoming volume envelopes over the overlap. Portrait groups the timeline and controls vertically; landscape keeps both decks visible beside independently scrolling controls. Drag a control point or use the numeric controls to adjust timing and level. Tap a numeric caption to enter a precise value. Linear, equal-power and smooth presets are also available.

Set the overlap, outgoing end trim and incoming cue. Each deck has low, mid and high EQ controls and an optional low-pass or high-pass sweep. EQ boosts include headroom. The allowed overlap follows the audio remaining in both tracks and the native transition engine's limits.

**Preview** auditions the draft with the real player. Stop, leave the editor or let the preview finish to restore the previous queue position, playback speed and play/pause state, provided the queue has not changed. Preview uses normal playback and may affect listening history. **Save** remembers the edit for this directed track pair on this device. **Automatic** removes the saved edit and returns that pair to the native planner.

The graph displays automation, not an audio waveform. Network availability, decoder support, source duration and the native two-player engine still determine whether a transition can play.
